# Botanicals Effectiveness Analysis 

## Overview
This analysis examines how different botanical substances perform as larvicides across four local governments in Lagos, testing various concentrations (ppm levels) to determine effectiveness

## Tools Used 
Excel, Python

## Dataset
Field and laboratory work collection

## Key Findings 
### Finding 1: Effect of Concentration
In all Local Governments, the pattern is the same: 200 ppm < 400 ppm < 600 ppm < 800 ppm
This means Higher concentration = Higher mortality = Better larvicide effectiveness

### Finding 2: Local Government Differences 
Overall Performance Ranking (Average Mortality Across All Concentrations): Effective botanical-concentration combinations
Alimosho 11.53 > Kosofe 8.45 > Amuwo-Odofin 7.78 > Ikorodu > 6.97
